# 연관어 연결과 겹친 카드

상태: 설계

## 0. 결정

사용자 요청(2026-10-22, 원문 요약): 세상 모든 것은 연결되어 있다("다섯 사람만 거치면 아는 사람"). 핵심 가치(D24 연결과 창조)를 직접 구현한다.
1. **연관어 연결**: 메모의 주제어에 대해 AI가 연관어를 몇 개 만든다. 다른 메모도 마찬가지. A의 연관어가 B의 연관어와 겹치면 A와 B가 이어진다. 예: 짜장면(요리) → 중국·검은색·국수 / 블랙먼데이(주가지수) → 검은색·월요일·하락 → "검은색"으로 연결.
2. **여러 주제에 속하기**: 메모 하나가 두 개 이상의 주제와 이어질 수 있다. 예: 김밥은 요리지만 소풍에도 들어간다.
3. **겹친 카드**: 연결이 있는 메모 카드 아래에 카드를 겹쳐 보인다(색은 연관 주제 계열). 누르면 아래 카드가 갈라져 두 장이 되고, 아래 카드를 누르면 그 주제로 이동하는 움직임. 이동한 주제의 그 메모도 똑같이 겹친 두 장 모습.

## 1. 확인한 사실

- 정돈 결과(`src/core/organize/types.ts`): `keywords`(1~5), `related: {id,strength,reason}[]`(최대 `MAX_RELATED`=5, AI가 최근 메모 `MAX_RECENT`=80 중에서 고름). 연관어·여러 주제 필드 없음.
- 링크 저장: `applyResult`가 `related`마다 `Link{id: linkId(a,b), fromId, toId, strength, reason}`를 `putLink`(`src/core/organize/apply.ts:72-81`).
- DB(`src/db/schema.ts`): v2, `memos: 'id, createdAt, status, topicId'`, `links: 'id, fromId, toId'`. 연관어 색인 없음.
- 연결 표시: D25 `connectedTopics`(`src/core/connections.ts`)는 고정 메모만. 카드 배지(`GlobeBoard.tsx` `CardMarks`), 상세 "연결된 주제"(`MemoSheet.tsx`).
- 카드 탭: 집중 상태 정면 주제 카드만 탭 → 상세(`GlobeBoard.tsx` onTap). 길게 누르기 = 주제 옮기기(D23). 정면 이름표·빈 곳 탭 = 하늘로(D29).
- 주제 회전: `motionBus` `focusTopic` → `engine.focusTo`(D25).
- 실제 AI 응답(2026-10-22, 일회성 스크립트): 새 주제 색 지시를 잘 따름 → 연관어 지시도 따를 가능성(가정, W1에서 실측).

## 2. 설계

### 2.1 데이터
- `Memo`에 선택 필드 `associations?: string[]`(정규화: 앞뒤 공백 제거, 영문 소문자). 색인 없음 → Dexie 버전 그대로.
- 연관어 연결은 저장 안 함(C3). `Link`는 지금처럼 AI `related`만.
- 연결 계산 `associationLinks(memos)`: 연관어 → 메모 목록 역색인 1회, 흔한 말 제외, 다른 주제 쌍만, 쌍마다 겹친 말(가장 드문 것)과 점수(드물수록 높음). 메모별 상위 3. 결과를 `useMemo`로 메모 목록이 바뀔 때만 다시 계산.
- 화면용 통합 `memoConnections(memo)`: 연관어 연결 + `related` 링크(다른 주제) → 주제별로 묶어 [주제, 이유, 상대 메모] 목록.

### 2.2 AI
- 분석 도구에 `associations`(3~5개) 추가. 요청에 `vocab`(흔한 말 제외 상위 150 연관어) 추가.
- 검증(`validate.ts`): 연관어 개수·길이(1~10자) 자르기, 공백 포함 말 제외.
- 기존 메모(C8): `/api/associate` — 메모 요약 최대 10개 + vocab → `{id, associations}[]`. `server/organize.ts` `handleApi`에 경로 추가.

### 2.3 화면(지구본)
- 뒤판: `.g-card` 안에 실제 요소 최대 2장(색·이름 표시 필요). 오프셋 (14px, 10px)·(26px, 18px), 회전 -3°·3°, 주제 색 번짐(D21). **정면에 펼친 주제의 카드만** 그림(성능).
- 펼침(C6): 뒤판이 카드 아래로 부채처럼 내려오고 각 장에 "주제 이름 · '검은색'"(연관어) / "· 관련 메모" / "· 이 주제에도". 펼친 동안 같은 주제의 다른 카드는 흐리게. 링 배치(D16)는 그대로, 펼친 장은 위에 떠서 그림.
- 이동: 아래 장 탭 → `focusTopic(그 주제)` → 도착 후 상대 메모 카드에 빛 1회 + 그 카드도 겹친 모습(대칭이라 자연히).
- 상세(새 메모장) "연결된 주제": `memoConnections` 전체. D25 배지 제거.

## 4. 종료 조건 (실행 전 고정)
1. 실제 AI(미리보기 서버)로 예시 4쌍(짜장면/블랙먼데이, 커피/새벽 공부, 바다/파란 셔츠, 비 오는 날/파전)을 넣었을 때 **2쌍 이상**이 서로 다른 주제에 들어가고 연관어 연결이 생긴다. 지시문 조정은 최대 1회, 미달이면 미완료로 기록하고 C2를 다시 설계.
2. 단위 테스트: 흔한 말 제외(15% 초과, 20개 미만 미적용) / 같은 주제끼리는 연결 없음 / 메모별 들어오고 나가는 연결 합쳐 최대 3 / 메모를 다른 주제로 옮긴 뒤 다시 계산하면 같은 주제가 된 쌍의 연결이 사라짐 / 검증이 공백 포함·긴 연관어를 버림.
3. e2e(`associations`를 채운 시드 DB): 연결 있는 카드에 뒤판 보임, 3개 이상이면 2장 + 숫자 / 첫 탭에 갈라짐(장에 주제 이름) / 아래 장 탭 → 정면 주제가 그 주제로 바뀌고 상대 메모 카드에 뒤판 보임 / 겹침 없는 카드는 첫 탭에 상세 / 갈라진 상태에서 빈 곳 탭 → 다시 겹침(하늘로 안 감).
4. e2e: D25 배지 요소가 더 이상 없고, 메모 상세 "연결된 주제"에 연관어 연결(겹친 말 표시)이 나온다.
5. 기존 메모 채우기(가짜 분석기): `associations` 없는 메모 30개 DB에서 처리 루프를 직접 돌린 뒤 30개 모두 `associations !== undefined`, `[]`를 받은 메모 재요청 0회, 주제·종류 불변, 하루 상한 100을 넘기지 않음.
6. 사용자 폰 확인 1회: "첫 탭 = 갈라짐"을 받아들이는지 예/아니오. 아니오면 C6을 "뒤판 가장자리만 펼침"으로 바꾼다.
7. build·lint·unit·e2e 통과.

## 5. 위험
- **연관어 품질**: 엉뚱한 연결이 소음이 됨 → 연결 이유(겹친 말)를 늘 보여 주고 흔한 말 제외. 실측 후 15% 조정.
- **AI 비용**: vocab로 요청당 약 1k 토큰 증가, 기존 메모 채우기 → 묶음·하루 상한.
- **억지 수렴**: vocab 때문에 AI가 기존 말에 끼워 맞춤 → 지시문 "맞는 말 없으면 새 말".
- **화면 비용**: 뒤판은 정면 주제만.
- **탭 의미 변화**: 겹친 카드만 첫 탭이 펼침 → §4-6에서 사용자 판단.
