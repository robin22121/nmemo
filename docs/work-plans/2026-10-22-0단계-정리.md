## §2 정의

- 내보내기 파일: `{ format: "kkeujeogim-export", version: 1, exportedAt, memos[], topics[], links[], moves[], batches[] }`, `memos[].photo`는 `data:image/jpeg;base64,…`. 파일 이름 `끄적임-YYYYMMDD-HHmm.json`.
- 가져오기 결과: `{ memosAdded, memosSkipped, topicsAdded, topicsMerged }`를 알림으로.
- 오분류율: 창 = `now−7일 ≤ organizedAt ≤ now`인 메모 N개, 그중 `organizedAt ≤ lockedAt ≤ organizedAt+7일`인 M개, x = M/N. N=0이면 "—".

## §4 종료 조건 (실행 전에 고정, 실행 중 바꾸지 않는다)

1. 운영에서 `/api/health`를 연속 155번 부르면 429가 1번 이상 나오고 그 뒤 호출은 모두 429(curl 출력). AI를 부르지 않는 경로라 비용 없음. **폰과 다른 네트워크에서 실행**(Mac과 폰이 같은 Wi‑Fi면 폰도 1시간 막힘 → 폰을 셀룰러로 쓰도록 사용자에게 알림). 요금제에서 규칙이 안 되면 F로 기록하고 Z2 대안으로.
2. 단위: 픽스처(jpeg가 아닌 사진 Blob 1개 이상 포함) 내보내기 → 빈 DB 가져오기 → 테이블별 개수 같음, 사진 Blob 바이트·type 같음, 다시 가져오면 추가 0. "사진 빼고" 내보내기는 사진 필드 없음.
3. 단위: 이름이 같은 주제(공백·대소문자 차이 포함)가 있는 두 파일 A·B를 A→B, B→A 순으로 가져온 결과가 같고(주제 수·메모 수), 주제 하나로 합쳐지며, `memos.topicId`·`moves`·`batches`·`links`의 참조가 모두 존재하는 행을 가리킴.
