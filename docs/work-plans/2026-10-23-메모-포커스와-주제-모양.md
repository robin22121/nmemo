## §2 정의

- 모양 = 정규화 꺾은선 목록 `[[x,y],…][]`(0~1), `src/core/shapes.ts`(순수). 표본 함수 `sampleShape(shape, n, box, avoidRect)` → 먼지 점 n개·메모 점 위치(카드 사각형 제외, 시간순으로 윤곽을 따라).
- 포커스 상태 = `{ topicId, memoId }`. 순서 = 같은 주제 메모 `createdAt` 오름차순.

## §4 종료 조건 (실행 전에 고정, 실행 중 바꾸지 않는다)

1. e2e(390×844, 자판 없음): 메모 카드 탭 → 포커스 카드의 중심이 화면 중심 ±8px, 폭 = 화면 − 68 ±2px, 긴 글은 카드 안에서 스크롤(카드 높이 ≤ 화면 42%).
2. e2e: 같은 주제 메모 수(≤24)만큼 점, 어느 점도 카드 사각형과 겹치지 않고 화면 안(가장자리 ≥ 12px), 점끼리 중심 거리 ≥ 26px. 손가락 왼쪽(dx −80) → 다음 메모(createdAt 오름차순), 오른쪽 → 이전, 점 탭 → 그 메모이고 그 점이 커짐. 마지막에서 다음은 그대로. 메모 1개 주제 = 점 0개, 2개 = 점 2개.
3. e2e: 빈 곳 탭 → 포커스 화면이 사라지고 마지막으로 본 메모의 카드 bounding box가 열기 전 값 ±2px·opacity 1. 포커스 중에도 배경 주제 하나 이상의 transform이 1.5초 사이 바뀜(F5). 포커스 중 메모 삭제 → 다음 메모로, 마지막 남은 메모 삭제 → 닫힘.
4. e2e: 기존 panel.spec 항목(편집 저장·빈 글·사진 설명·종류·감정·완료·주제 바꾸기·새 주제·삭제)이 포커스 카드에서 통과. 연결 줄이 보이고 누르면 관련 메모·이동 기록이 펼쳐짐. 편집 중에는 점이 숨고 카드 아래 끝이 visualViewport 안.
5. 단위: `sampleShape`가 카드 사각형을 피하고 순서를 지키며 n=0·1·2·30에서 깨지지 않음(n=0 → 빈 배열), 12개 모양 모두 표본이 상자 안. 정돈·재정리 검증이 목록 밖 모양을 버림. 재정리는 모양이 있는 주제의 모양을 안 바꿈. 내보내기·가져오기가 shape·shapeReason을 보존.
6. 실제 AI: 새 주제 정돈 2건 + 재정리 2건에서 모양이 목록 안이고, `shapeReason`이 그 주제 메모 본문의 단어·사건을 하나 이상 가리킴(4건 중 3건 이상).
7. 캡처: 12개 모양 점 그림(메인 확인, 각각 무엇인지 알아보임), 포커스 화면 2개 주제(다른 모양) + 긴 글 1장. 사용자 폰 확인 1회(일정은 사용자 몫): 모양 이름 없이 2개 주제의 모양을 맞히는지, 밀기·점 탭이 자연스러운지, 배경 자전 중 끊김 없는지.
8. build·lint·unit·전체 e2e 통과.
